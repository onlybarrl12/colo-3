BUDGET MITRA — SERPL Login Page (Sample #2)
=============================================

Two ways to open the page:

1. login-standalone.html
   Single self-contained HTML file (images embedded as base64).
   Double-click it — opens anywhere.

2. login.html + logos/
   login.html loads images from the logos/ folder next to it.
   Easier to edit — swap any image without touching HTML.
   Keep both together in the same folder when opening.

Admin controls on the login page
--------------------------------
• Camera icon on the ED & RH avatar → upload a new portrait photo.
• Pencil icon next to the message heading → edit heading, body text
  and signature inline; click Save (all changes persist in the browser).
• "Reset photo" and "Reset text" links appear only when custom
  values are set — click to revert to defaults.
